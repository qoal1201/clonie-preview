# Material Icon Theme provenance

The inline file icons in `Sources/Clonie/Resources/ChatHTML.swift` are copied
from [PKief/vscode-material-icon-theme](https://github.com/PKief/vscode-material-icon-theme)
at commit
[`db37396672f801195be1bf082cca76942deb8c24`](https://github.com/PKief/vscode-material-icon-theme/tree/db37396672f801195be1bf082cca76942deb8c24)
(release `5.38.1`, MIT). The selected source files are:

| Clonie asset | Upstream file |
| --- | --- |
| `claude` | `icons/claude.svg` |
| `agents` | `icons/agent.svg` |
| `gitignore` | `icons/git.svg` |
| `markdown` | `icons/markdown.svg` |
| `swift` | `icons/swift.svg` |
| `shell` | `icons/console.svg` |
| `javascript` | `icons/javascript.svg` |
| `typescript` | `icons/typescript.svg` |
| `python` | `icons/python.svg` |
| `json` | `icons/json.svg` |
| `yaml` | `icons/yaml.svg` |
| `pdf` | `icons/pdf.svg` |
| `image` | `icons/image.svg` |
| `text` | `icons/log.svg` |
| `default` | `icons/document.svg` |

The SVG markup is embedded inline because the app loads this screen with
`loadHTMLString(baseURL: nil)` and cannot depend on external runtime assets.
