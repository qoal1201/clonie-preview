# Upstream attribution

Clonie started from [rbc33/Ghostbar](https://github.com/rbc33/Ghostbar).
The upstream reference used by this source lineage is commit
`7d895c0853075b4cd1b24e25f3f6d43de95b794d`.

The purpose and interface have changed substantially, but this is a derivative project.
Some original audio, streaming, and application startup source files remain.
The original project and its contributors retain their respective rights.

On 2026-09-10, the upstream README's comparison table described Ghostbar as
“Open source” and “MIT”. There was no standalone LICENSE or COPYING file in
the upstream repository root, and the GitHub license API returned null.
This notice preserves that distinction; it does not claim that an upstream
maintainer supplied a missing license file or separately approved this release.

Clonie's modifications are made available under the MIT license in LICENSE.
Upstream material retains the license identified by its original project.

Changes include a Markdown workspace, local embedding search, file editing
and autosave, practice and input records, and a local MCP server.

personal documents, research notes, vault data, and local account settings.
