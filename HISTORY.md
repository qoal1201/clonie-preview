# Project history

Clonie is a macOS workspace for user-owned Markdown. Current app, package, and MCP identities use Clonie.
The app reads its own settings and models; it does not migrate another product's installation.

Older published previews and their source revisions remain historical records, not the specification
for the current product. Current behavior and first-install verification must be checked against
the corresponding release artifact, rather than inferred from earlier previews.

The licenses and notices for components included in the current build are listed in
[ThirdPartyNotices](ThirdPartyNotices/README.md). Existing distributed copies retain
the notices that accompanied them.
