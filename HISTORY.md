# Project history

Clonie development began in a working copy of [rbc33/Ghostbar](https://github.com/rbc33/Ghostbar),
using upstream commit `7d895c0853075b4cd1b24e25f3f6d43de95b794d`.
The published previews through [preview-20260910-logo1](https://github.com/qoal1201/clonie-preview/releases/tag/preview-20260910-logo1)
contained original audio, streaming, and startup code. Those releases, source revisions, and their notices remain unchanged.

On 2026-09-10, Clonie removed the unused chat, Whisper recording, screenshot, and streaming paths and the old favicon.
The application entry point, window assembly, hotkeys, backend preferences, model-list requests, and packaging were rebuilt
for the Markdown workspace. Current app and package identifiers use Clonie; old identifiers remain only where needed
to read an existing installation's preferences and model files.

This history does not imply endorsement by the original project. Licenses for the third-party components still included
in the current build are preserved in [ThirdPartyNotices](ThirdPartyNotices/README.md).
